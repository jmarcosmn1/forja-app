# Forja — app web instalável (iPhone e Android)

Desenvolvido por J MARCOS.

Abra o link do GitHub Pages no celular:
- **iPhone (Safari):** botão Compartilhar → "Adicionar à Tela de Início".
- **Android (Chrome):** menu ⋮ → "Instalar app" (ou "Adicionar à tela inicial").

Os dados (treinos, marcações e histórico) ficam no próprio celular de cada pessoa.
Para levar para outro aparelho: aba Agenda → Backup.
